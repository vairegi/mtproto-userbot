## v12.45 — Bot2Fetcher: direct nhentai detail fetch when Turso has no row

Ship date: 2026-08-26
Files: app/fetcher.py, app/mongo_state.py
(superset — includes v12.42, v12.43, v12.44)

Symptom (Render log): galleries from the NEW recent-first queue (v12.44)
arrived with "no row in Turso" → "no cached meta, dropping claim". These
are brand-new uploads whose detail pages BOT 1's details sweeper has not
cached yet. The v12.43 cover-construction fix only runs AFTER a row exists
— this was a different gap.

Fix (Ryan's rule: if Bot 2 doesn't find it, fetch it itself):

1) fetcher.py — new _fetch_meta_direct(gid): on meta_from_cache() == None,
   fetch GET https://nhentai.net/api/v2/galleries/<id> directly with a
   browser UA, hoist v2 images.cover/thumbnail to top level (so meta's
   _construct_cover_url gets exact extensions), and run the payload through
   the SAME meta_from_cache + v12.44 coercion pipeline. Job then continues
   normally (PDF request, cover post, DB channel post).
   Outcome handling:
     * 404            -> "dead": mark_failed(FAILED_SCRAPE), never retried.
     * 403/429/5xx/net -> "defer": NEW Galleries.defer_claim() parks the row
       for 1h (claim_expires = now+3600) instead of deleting it — no
       hammering nhentai every scan cycle during a Cloudflare flap.
     * unusable body  -> drop + known_failed (never re-queued this process).
   Deliberately does NOT write the raw payload into the shared
   nhentai_cache table — raw v2 JSON breaks the Mini App detail view; BOT 1
   normalizes for that reason and will cache it properly on its own sweep.
   Rate impact: worst case one request per uncached gid, ~4-8s apart per
   slot — well under nhentai's 20/min /galleries anon limit. Steady state
   is near zero because BOT 1 pre-caches most galleries.

2) mongo_state.py — new Galleries.defer_claim(gid, cooldown_s=3600).

Verified: py_compile + pyflakes clean; full raw-v2 payload smoke-tested
through meta_from_cache (title dict, {"t":"p"} cover dicts, cover URL
construction, caption build all pass).
