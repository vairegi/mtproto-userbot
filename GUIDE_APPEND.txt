v12.55 — One detail sheet for the whole app + smooth "Similar to this" scroll
Ship date: 2026-08-27

WHAT WAS WRONG:
  The app had THREE separate detail-sheet implementations:
    - plugins/detail-sheet.js  → the rich one (Similar to this, star rating,
      Saves row) — used by Random, Popular-Now rows, Profile, deep-links.
    - pages/search.js          → an old INLINE copy — used by every grid card
      (Popular Now / New Uploads / Popular Week / search results).
    - pages/bookmarks.js       → a third, minimal inline copy (Saved tab).
  Every update to detail-sheet.js only ever reached Random — the grid sorts
  opened the frozen inline copy.

WHAT CHANGED:
  search.js    — inline openDetail (110 lines) DELETED; card taps now open
                 the shared rich sheet. v2_status prefetch kept (correct
                 Download button label on first paint).
  bookmarks.js — inline openDetail DELETED; Saved-tab cards open the shared
                 rich sheet too.
  detail-sheet.js — "Similar to this" strip scrolling fixed:
                 snap changed mandatory → proximity (no more "stuck" feel),
                 cards slightly smaller (next card peeks = obvious scroll
                 affordance), iOS momentum + pan-x touch + hidden scrollbar.
  app.js / profile.js / home-rows.js / search.js random chip / index.html —
                 all detail-sheet.js references bumped to ?v=12.55 so phones
                 pick up the new files.

RESULT:
  One sheet for the entire app. Any future sheet update ships to ALL sorts,
  Saved, Random, Profile and deep-links automatically.

DEPLOY:
  1. Copy these 7 files into the repo, commit, push — Render auto-deploys.
  2. Fully close the Mini App once (swipe away) and reopen.
  3. Open any gallery from ANY sort — you should see star rating, Saves,
     and the horizontally scrollable "Similar to this" strip.
