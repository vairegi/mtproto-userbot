WHAT IT IS
  One canonical payload schema for nhentai_cache, enforced at WRITE time:
    gallery:<id> -> id str, title str, cover FULL https URL, pages int,
                    favorites int, upload_date str, scanlator str,
                    tags [{name,type}], tag_groups {type:[names]}
    search:*     -> [ {id str, title str, title_en_clean str,
                       cover FULL URL, pages int, tags []} ]
  Every write passes through normalize_for_write(key, payload, source).
  Invalid rows are REFUSED with a loud WARNING carrying source bot, key,
  gallery id and the exact failing field. suggest:/trending:/bm:cover: and
  all non-shared keys pass through untouched. Transports unchanged:
  BOT 0 stays sync (v12.46 raw HTTP), BOT 1 stays async.
