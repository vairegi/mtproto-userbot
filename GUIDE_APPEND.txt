## v12.40f — Bot2Fetcher rest only after real work (2026-08-23)

### Symptom (v12.40e log)
    🚫 619612 previously failed — skipped
    ⏸ slot 1 resting 27s
    🚫 571509 previously failed — skipped
    ⏸ slot 1 resting 48s

With ~10 tombstoned galleries at the head of the queue the slot sat idle
for ~5 min chewing through skips at 20-60 s each.

### Fix
1. `_do_job` now returns bool: True = real work attempted, False = skip.
2. Slot loop rests ONLY when did_work == True. Skips (done / failed /
   busy) loop to the next queue item instantly.
3. Default rest window is now 3-8 s (was 20-60 s). Env overrides:
   FETCH_GAP_MIN_S=3, FETCH_GAP_MAX_S=8. Existing operators can raise
   these via Render env if they want a slower cadence.

### Rollout
Copy `Bot2Fetcher/` over, push, Manual Deploy. Env unchanged.
