NEW BEHAVIOR
------------
1) @Gallery_DLBot replies with ANY error text → the same link is DM'd
   immediately to the fallback bot (default @pdfdownloadcinbot), wait
   ≤5 min (BACKUP_PDF_TIMEOUT_S). The old 3-strike "no images" counter
   is retired as a decision-maker (field remains for history).
2) Fallback replies with a document → identical success path (cover +
   spoiler post, PDF forward, mark_completed, BackupDB mirror).
3) BOTH bots fail → Mongo doc parked 12h (claim_expires AND started_at
   pushed +12h so Bot 0's staleness clock respects it), loud alert to
   the Bot 2 LOG_CHANNEL with both bots' error text and the link.
4) After the 12h park, the next claim routes STRAIGHT to the fallback
   bot — @Gallery_DLBot is skipped for that gid.
5) Legacy FAILED_BOT2_ERROR docs (the old permanent skips, ~124 rows)
   become reclaimable 12h after their last failure and also go straight
   to the fallback bot.
6) Single-flight: in-process asyncio.Lock (Layer A) + Mongo
   fallback_lease doc (Layer B). Two slots can never DM the fallback
   bot at once; a crashed owner self-expires after FALLBACK_LEASE_S
   (default 420s > the 5-min wait). Mongo blips fail OPEN to the lock.
7) Timeout on @Gallery_DLBot (silence, no explicit error) is unchanged:
   claim dropped, retried next process run — per spec, the fallback
   triggers on error TEXT only.

DEPLOY (Render, Bot2Fetcher service)
------------------------------------
1) Drop the zip onto the repo, push.
2) New env var (required to activate the chain):
       BACKUP_PDF_USERNAME=pdfdownloadcinbot
   Optional overrides:
       BACKUP_PDF_TIMEOUT_S=300      # fallback wait
       BOTH_FAIL_PARK_S=43200        # 12h park
       FALLBACK_LEASE_S=420          # cross-process lease TTL
3) IMPORTANT: each userbot session (STRING_SESSION, STRING_SESSION_2)
   must have DM'd @pdfdownloadcinbot at least once, or the boot log will
   show "CANNOT resolve fallback bot … chain DISABLED for this slot"
   (non-fatal; the primary chain keeps working).
4) Redeploy. Boot log should show "🛟 slot N resolved fallback bot".
