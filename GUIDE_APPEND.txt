Rating removal + trending-chip fix + live online badge
================================================================================

1) RATING REMOVED (detail sheet)
   The star-rating widget is gone from the gallery detail sheet (import,
   render call, and the vestigial try/catch dropped). star-rating.js stays
   in the repo unused — ratings data in Mongo is untouched if you ever
   want it back.

2) TRENDING CHIPS FIXED ("Try Searching These")
   Before: tapping a chip pasted "tag:blowjob" into the search box. Bot 1
   warms searches under the bare-slug canonical key
   (search:q=blowjob|sort=popular-today|page=N), so the tag: form was a
   guaranteed cache MISS — wrong sort + slow live fetch.
   Now: chip pastes the bare slug ("blowjob") and the existing input-event
   -> debounced-commit flow fires the search automatically.
   Result: chip taps now hit the warmed cache instantly.

3) LIVE ONLINE BADGE (header, in front of PUBLIC)
   New "🟢 N" badge = users with last_seen in the last 5 minutes.
   Backend: NEW miniapp/backend/app/routes/online.py — GET /api/online
   (authenticated, one count_documents on miniapp_users.last_seen;
   last_seen is already maintained on every request, so this adds zero
   write load). Frontend: app.js polls every 30s.
   Tunable: ONLINE_WINDOW_MIN on the miniapp service (default 5).
