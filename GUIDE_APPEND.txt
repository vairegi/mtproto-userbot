================================================================================
GUIDE_APPEND — v1.28 (2026-09-05) — Turso -> second-Mongo backup (ScraperBot)
================================================================================

WHY
---
Turso free tier hard-locks at 500M reads/month. The v12.57 brake + Bot 2
suspension fixed the burn (7M/70min -> ~10k/9h), but if the account ever
locks while you're away, the entire cache is unreachable. This mirrors all
content into your SECOND Mongo cluster (separate account) every 12h.

WHAT
----
NEW ScraperBot/app/services/turso_backup.py — a background task inside
ScraperBot (no new Render service). Every 12h it copies:
    nhentai_cache, bot2_fetch_state, bot2_done
into Mongo-2 collections turso_nhentai_cache, turso_bot2_fetch_state,
turso_bot2_done via bulk upserts. Keyset pagination (key > :last, 500-row
batches) — no OFFSET scans. Cost ~19k Turso reads/pass (~0.2% of budget).
Manual restore mode: python -m app.services.turso_backup --restore

CHANGED: ScraperBot/main.py (import + task wiring, starts 120s after boot).

FILES IN THIS ZIP
-----------------
  ScraperBot/app/services/turso_backup.py   (new)
  ScraperBot/main.py
  GUIDE.md
  GUIDE_APPEND.txt

DEPLOY (step by step)
---------------------
1) Drag-and-drop the zip onto the repo root. Commit + push.
2) Render -> ScraperBot service -> Environment, add:
     2NDMONGO_BACKUP_TURSO = mongodb+srv://<2nd-cluster-uri>
   (If Render rejects the name, use MONGO2_BACKUP_URI instead — the code
   reads both.)
3) Redeploy ScraperBot only. Bot 0 / Bot2Fetcher untouched.
4) First backup fires ~2 min after boot; watch Render logs for:
     "turso_backup: starting (every=12.0h, enabled=True)"
     "turso_backup: nhentai_cache -> 18930 rows"
     "turso_backup: done ok=True tables={...}"

VERIFY
------
  * If the URI env is missing, the task logs "not set — skipping" and
    idles harmlessly (zero Turso reads).
  * BACKUP_ENABLED=0 idles the loop without a redeploy of code.
  * Mongo-2 (Atlas UI): collections turso_nhentai_cache etc. appear with
    row counts matching Turso.

TESTS (sandbox)
---------------
