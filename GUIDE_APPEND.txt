v12.56 — "Similar to this" polish + Turso similar-cache disabled
Ship date: 2026-08-27

FRONTEND (detail-sheet.js):
  * Heading brighter + bigger: 12px dim → 13px bold var(--du-ink-mid),
    uppercase, with an inline "scroll →" hint on the right so users see
    the label AND know the strip is scrollable.
  * Section separation: marginTop 14→22px, paddingTop 12→18px,
    borderTop 1px → 2px, brighter divider color. Reads as a distinct
    block below the metadata/actions instead of a footnote.
  * Strip wrapped in a positioned container:
      - `contain: content` isolates layout/paint (fixes Android WebView
        stealing horizontal touches),
      - `touchAction: pan-x` on both wrapper and strip,
      - right-edge fade gradient (28px, pointer-events:none) as a peek
        affordance so more items are obviously off-screen.
  * scrollSnapType stays "proximity" — no more "stuck" feel.

BACKEND (services/scraper_bridge.py):
  * `similar:<gid>` Turso caching DISABLED.
    - No cache read, no cache write on gallery_suggestions().
    - Engine (Stage A/B/C) still runs and still logs
      `similar(gid): stage=A returned=N`.
    - Rationale:
        + Turso SQL scoring already answers in ~1.2-1.5s.
        + Caching burned ~500K writes/mo (one per opened gallery) for
          data that stales as new galleries land.
        + Users always get fresh recommendations reflecting the current
          library.
        + Frees ~1GB of Turso storage over time.
    - `gallery:<gid>` and `search:*` caches are untouched (still 30-day
      / 3-day TTL) — those are the ones that matter.

VERSION BUMPS:
  All detail-sheet.js import specifiers → ?v=12.56
  (index.html app.js, app.js dynamic import, search.js Random chip +
   card taps, bookmarks.js, profile.js, home-rows.js)

DEPLOY:
  1. Copy the 8 files into the repo (frontend + one backend file), commit,
     push — Render auto-deploys.
  2. Fully close the Mini App once (swipe away), reopen.
  3. Open any gallery — you should see:
       * A clear "SIMILAR TO THIS   scroll →" heading in bright text.
       * A distinct visual gap above the strip.
       * Smooth horizontal swipe with a fade at the right edge.
       * Log line `similar(<gid>): stage=A returned=N` — but NO
         `[TURSO WRITE] key=similar:<gid>` line.
