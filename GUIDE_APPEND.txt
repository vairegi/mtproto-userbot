GUIDE_APPEND — v13.01 (2026-09-15) — shortener polish: drop /shortenerlimit, add /verifymsg
WHAT: Follow-up on the v13.0 link-shortener gate. (A) /shortenerlimit removed
entirely — it was counted but never enforced, and a daily cap would have
broken the 6h re-verify loop; TTL (/setverifytime, def 6) is now the only
unlock-duration control (visits still counted for stats). (B) New admin
command /verifymsg <text> edits the post-verification SUCCESS message Bot 0
DMs ("Verified! Full access unlocked for {hours} hour(s)."); {hours} fills
the current TTL, "clear" resets to default. Re-verifying does NOT stack
hours — each verify resets unlocked_until = now + TTL.
FILES: admin_bot.py, miniapp/backend/app/services/shortener.py, GUIDE.md,
GUIDE_APPEND.txt.
DELETE: none.
DEPLOY: drop on repo root, commit, push, redeploy Bot 0 ONLY. No new env vars.
VERIFY: /shortener status no longer shows a limit line; /verifymsg Enjoy! ✅
then complete a verify as a non-admin → the bot replies "Enjoy! ✅" instead
of the default; /verifymsg clear restores the default. /help's shortener
section lists /verifymsg and no longer lists /shortenerlimit.
